# 主题与壁纸（dsh-theme-wallpaper）

一个 DeepSeek Harness 桌面端插件：给聊天界面换上 macOS 观感主题，并支持把**任意本地图片 / 动图 / 视频**设成背景壁纸——包括从 **Wallpaper Engine 导出包（.mpkg）自动解出的高清动态壁纸**。

> **适配**：本插件同时兼容 **DSH 官方桌面端** 与 **自打包桌面端（如 `deep seek HARNESS` / DSH-Little-Blue-Whale 系列）**。渲染层对自打包桌面端的标题栏做了专门适配——壁纸覆盖整个窗口（含顶部红绿灯标题栏区域），与界面融为一体；对官方桌面端则保持通用的透明表面渲染。两者共享同一份代码，无需单独分支。

## 功能特性

- 🎨 **macOS 观感主题**：设置里一键切换（模型 / Agent 预设 → 主题与壁纸）。
- 🖼 **任意本地壁纸**：静态图（jpg/png/webp）、动图（GIF/WebP）、视频（mp4/webm/mov/mkv）；可指向任意绝对路径。
- 🎚 **壁纸暗化 + 面板半透明**：两个滑杆，让壁纸既不刺眼又能透过面板看到，贴合"无缝壁纸"观感。
- 🔍 **文字可读性保护**（默认开启）：
  - **文字描边**：给对话与输入框的文字加一圈极淡的光晕——浅色壁纸配深字、深色壁纸配浅字自动切换，字在任何背景上都立得住，且不占用布局、不改变字号。
  - **对比度实时读数**：按 WCAG 标准算出当前设置下**最差位置**的对比度，直接告诉你"现在能不能读"，低于 4.5:1 会变色提醒并给出该怎么调。
  - **滑杆安全区标记**：面板半透明滑杆的轨道上直接标出绿色安全区，你一眼能看出"至少要开到多少"。阈值随壁纸和暗化实时变化，不用盲调。
- 🎥 **失焦自动暂停**：窗口失去焦点时自动暂停背景视频，省电。
- 📐 **对齐方式**：覆盖 / 填充 / 拉伸 / 自由，任选。
- ⚡ **Wallpaper Engine 高清动态壁纸**（核心卖点）：
  - 在 WE 里右键壁纸 → **发送到移动设备**，会导出一个 `.mpkg` 包（内含 WE 引擎渲染好的高分辨率 `wallpaper.mp4`）。
  - 插件自动解包，得到**比缩略图清晰得多的高清动态壁纸**（实测 3792×2128 / 2560×1440，远超 WE 库里的低清 preview）。
  - **专用导出文件夹**：你可以选一个已有文件夹或新建一个，插件**只扫这个文件夹**；WE 导出总落在桌面，点一下「**收桌面 .mpkg**」就自动移进你的文件夹，桌面不会堆文件。
  - 画廊里只显示已转换的高清条目（带「高清」角标），不再被 WE 库的低清缩略图刷屏。

## 安装

把 `lib/`、`client.js`、`package.json` 放入 DSH 桌面端的插件目录（profile 插件，重启 DSH 桌面应用生效）。

> 提示：宿主（`lib/index.js`）改动需要**重启 DSH 桌面应用**才加载；客户端（`client.js`）刷新页面即可。

## 使用方法

1. 打开 **设置 → 主题与壁纸**。
2. **主题**：选 macOS 观感。
3. **壁纸**：
   - 「选择本地文件…」或直接粘贴文件完整路径 → 应用；
   - 或「从 WE 导出包(.mpkg)选择…」：
     - 先设一个**导出目录**（「浏览文件夹…」逐层找到你的文件夹并选定，或「创建新文件夹…」填路径自动创建）；
     - 在 Wallpaper Engine 里对该壁纸右键 → **发送到移动设备**（导出默认落在桌面）；
     - 回插件点「**收桌面 .mpkg**」→ 桌面上的 `.mpkg` 自动移入导出目录并出现在画廊；
     - 点画廊里的高清条目即设为壁纸。
4. 用滑杆调 **壁纸暗化** 和 **面板半透明**。
5. 若文字看不清：先看「面板半透明」滑块下的**对比度读数**，它会告诉你当前是否达标；滑杆轨道上的绿色区是正文清晰所需的最低透明度。也可以直接开「文字描边保护」。

## Wallpaper Engine 位置自动检测

安装位置**不硬编码**：插件启动时通过 Steam 常见安装目录 + 解析 `libraryfolders.vdf` 自动探测（纯文件系统，不依赖注册表/外部进程），支持多 Steam 库、换盘换电脑。

高级覆盖（按优先级）：

| 方式 | 说明 |
| --- | --- |
| 环境变量 `STEAM_PATH` | 指定 Steam 根目录 |
| 环境变量 `WE_DIR` | 直接指定 WE 壁纸库目录（`…/steamapps/workshop/content/431960`） |
| 客户端 `?dir=` | 请求参数覆盖（社区/高级用户，配合 `?lib=1` 浏览完整 WE 库缩略图） |

## 文字看不清怎么办（可读性）

壁纸在面板背后，文字要和"恰好压在下面"的颜色竞争。插件提供三层保护，从自动到手动：

| 手段 | 做什么 | 何时用 |
| --- | --- | --- |
| 文字描边保护 | 给文字加极淡光晕（浅底深晕 / 深底浅晕自动切换） | 默认开着即可，觉得发毛就关 |
| 对比度读数 | 按 WCAG 算出最差位置的比值，< 4.5:1 变色提醒 | 调滑杆时实时参考 |
| 滑杆安全区 | 面板滑杆上画出绿色安全区 | 想知道"至少开到多少" |

对比度按 **WCAG 相对亮度公式**计算，并对壁纸做 32×32 采样，取所有采样点里**最不利**的那个——因为一个看不清的字就足以毁掉阅读。同时兼顾浅色与深色两套主题，取两者中更难的那个。

实测 26 张壁纸的结论：暗化到 **35% 左右是甜蜜点**，此时面板约需 47%；继续加大暗化到 50% 几乎不再降低面板需求，只会白白压暗壁纸。

## 数据与缓存

- `state.json`：运行时配置（主题 / 壁纸 / 导出目录），**不进仓库**，缺失时自动用默认值。
- `.mpkg-cache/<名字>/`：每个 mpkg 解出的 `wallpaper.mp4` + 预览图缓存，按 mtime 判新、重复扫描不重读大文件。解包是**流式**的（`createReadStream` → `createWriteStream`），所以 2 GB 级别的导出包也不会吃满内存。

## 安全模型

宿主 `dsh-host-webserver` 不提供服务级鉴权，因此本插件自己约束请求面：

| 路由 | 限制 |
| --- | --- |
| `GET /theme-wallpaper/file` | 只允许当前壁纸所在目录、mpkg 导出目录、mpkg 缓存在内的路径；白名单外一律 403 |
| `GET /theme-wallpaper/dirs` | 只返回目录名与 `.mpkg` 文件名，**不返回任何文件内容** |
| `POST /theme-wallpaper/mpkg-collect` | 只从桌面 / 下载目录移动 `.mpkg` |
| 全部 POST | 请求体上限 1 MB |

环境变量 `THEME_WALLPAPER_COLLECT_ROOTS`（分号分隔）可改写收集来源目录，仅供自包含测试使用。

## 面板半透明的工作原理

`--dsw-alias-bg-layer-*` 与 `--dsw-alias-bg-overlay` 通过宿主的 `ctx.theme.overrideTokens()` 下发，值为 `{ light, dark }` 成对。这样做的原因：宿主的 `ui-layout` 会把主题 token 写成 `<body>` 的 inline custom property，优先级高于样式表——任何插件一旦注册主题覆盖，样式表里写的同名变量就会失效。宿主未提供 `theme` 服务时，插件回退到纯样式表实现。

## 常见问题

- **为什么有的 .mpkg 不显示？** 只有"发送到移动设备"的导出（内含渲染好的 `wallpaper.mp4`）才能转成动态壁纸。有些包（如裸场景包 `PKGM0020`，只有 preview.gif + 模型素材）没有渲染视频，会被自动跳过并**明确列出跳过原因**。
- **导出目录设了但显示"未设置"？** 旧版本有"保存时清空目录"的 bug，已修复；如仍遇到请重启 DSH 应用。
- **WE 导出为什么落在桌面？** 那是 WE 自身的行为，插件用「收桌面 .mpkg」一键帮你收进导出目录。
- **装了很多壁纸，为什么只显示一部分？** 单个 WE 壁纸包内的素材数量有 40 条上限，超出的数量会在扫描结果里以 `truncated` 回报。
